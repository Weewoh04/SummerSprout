# Summer Sprout

A warm, cheerful Next.js lifestyle site for parents looking for summer activities, kid-friendly meals, printables, routines, and simple family fun ideas.

## Run locally

```bash
npm install
npm run dev
```

## Content model

Starter content lives in `data/siteData.ts` and is organized for easy expansion:

- `blogPosts`
- `activities`
- `meals`
- `printables`
- `bucketListGroups`

Ad, email, Pinterest, and sharing integrations are represented by reusable placeholder components and comments where production services can be connected later.
